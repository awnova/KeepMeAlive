# KeepMeAlive Solo

KeepMeAlive Solo adds a second chance after lethal damage in **SPT 4.1.x**. Your PMC enters a timed critical state instead of dying, and you can try to revive yourself before you bleed out.

This is the single-player build. It has no co-op features: no teammate revive, drag, defibrillator, or team medical, and it does not need Fika. For co-op, use the Fika build in `KeepMeAliveFika` instead.

The release includes a BepInEx client plugin and an SPT server mod. The server manages gameplay settings and revive lives and cooldowns. The client provides the downed state and the self-revive.

Based on the original revival mod by **KaikiNoodles** and **thuynguyentrungdang**.

## Features

- Self-revive with configurable timing, lives, and optional stim use.
- Configurable recovery after revival, including health restoration, status effects, and temporary invulnerability.
- Configurable downed movement, protections, and an optional chance that a headshot kills outright.
- Localized on-screen text, with support for adding your own languages.

## Requirements

- SPT 4.1.x

Do not install this alongside the Fika build of KeepMeAlive; they share the same mod ID and files.

## Install

Drop both the `BepInEx` and `SPT_Runtime` folders from the release into your SPT installation, keeping their folder structure.

KeepMeAlive creates its server and client configuration files the first time each is started.

All KMA client mods install into the one `BepInEx/plugins/KeepMeAlive` folder and share `BepInEx/plugins/KeepMeAlive/Localizations`: one `<code>.json` per language (EFT language code, e.g. `ru`). Each mod reads only the keys it uses and ignores the rest. The master text is `Localization/en.json` in this repo.

## Play

When you take lethal damage you go down instead of dying. Your body falls limp and you crawl at a reduced speed while the bleed-out timer counts down. Bots stop targeting you, and you cannot be killed while downed (unless a headshot rolls fatal, if you enable that).

Hold the self-revive key (default `F`) to use a stim on yourself. If the hold completes you get back up with part of your health restored, heavy bleeds stopped, and a short period of reduced damage and slower movement. Each revive spends lives from your per-raid pool (5 by default); run out and your next down is final.

To give up, press the configured key (default `Backspace`) while downed.

If the bleed-out timer runs out, you die.

## Configuration

Server gameplay settings are in `user/mods/KeepMeAlive/config.json` inside `SPT_Runtime`. The server creates this file with defaults and shares its settings with the client. Restart the server after editing it. A `config.json` generated by an earlier version keeps its old values until you edit or delete it.

### Downed state

`Gameplay.Downed` has: `MaxLivesPerRaid` (5, 0 = unlimited), `CriticalStateSeconds` (180), `DownedMovementSpeedPercent` (50), `ApplyContusionOnDowned` (on), `ApplyStunOnDowned` (on), `BlockUiWhenDowned` (on) and `UnconsciousOnDowned` (off).

### Self-revive

`Gameplay.Self` has: `Enabled`, `HoldSeconds` (8), `LivesCost` (1), `AllowInsufficientLives` (off by default: with fewer lives left than `LivesCost`, but at least one, the revive still works and uses up the rest, so the next down can't be revived), `RestoreBodyParts`, `RestorePercent` (Head 20, Chest, Stomach, Arms and Legs 35), `RemoveLightBleeds` (off), `RemoveHeavyBleeds` (on), `RemoveLegFractures`, `RemoveArmFractures`, `InvulnerabilityDurationSeconds` (10), `InvulnerabilitySpeedPercent` (60), `CooldownSeconds` (240), `ApplyContusionOnRevive`, `ContusionDurationSeconds` (10), `ApplyPainOnRevive` and `PainDurationSeconds` (30).

It also has `RequireStim` (off by default: you must carry a stim) and `ConsumeStim` (off by default: the stim is deleted when the revive starts, and only applies with `RequireStim` on). `Gameplay.StimItemIds` lists the stim template ids in priority order (the first one you carry is used); leave it empty for the game's Adrenaline stim. An old single `StimItemId` is moved into the list.

### Protection

`Gameplay.Protection` has: `BlockDeathInCritical` (on), `EnableGodMode` (on), `EnableGhostMode` (on) and `DeathFromHeadshotChance` (0: never; 0.25 is 25%; 1 is always).

`Gameplay.Development.DebugMode` (off) turns on extra logging for bug reports.

The config schema is version 1; an older `config.json` is rewritten with defaults for the new sections.

### Client

Client-only options are in `BepInEx/config/com.keepmealive.solo.cfg`: the self-revive key (`F`), the give-up key (`Backspace`), the tinnitus ring (on) and the language (Auto follows the game's language).

## Troubleshooting

- **Self-revive is unavailable:** Check that it is enabled in the server config, you have enough lives, and you carry the configured stim if `RequireStim` is on.
- **Settings aren't applied:** Check the server log for `[SyncConfig]` warnings and confirm `SPT_Runtime/user/mods/KeepMeAlive/config.json` exists. Restart the server after editing it.
- **A setting still has an old value:** An existing `config.json` is not reset when defaults change. Edit it or delete it to regenerate.

## Build from source

Run `build.ps1` in this folder to build both projects in Release mode. The package is assembled under `Build/KeepMeAliveSolo`. The client project expects SPT at `C:\SPT` by default; set the `SPTBaseDir` MSBuild property to your SPT client installation path when building elsewhere.
